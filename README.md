### Проект “Учёт сотрудников, проектов и задач”  
#### **Описание**  
Приложение позволяет вести базу сотрудников, проектов и задач с возможностью анализа, расчёта зарплат, импорта из CSV и визуализации данных через удобный графический интерфейс (Tkinter).

#### **Быстрый запуск**  
1. Установите зависимости  
Вам понадобятся Python 3.10+ и библиотеки: pip install pandas psycopg2
2. Разверните базу данных PostgreSQL  
Создайте базу и таблицы.  
Параметры доступа и пароль указываются через переменные окружения:

DB_HOST; DB_NAME; DB_USER; DB_PASSWORD; DB_PORT;

По умолчанию:  
host: localhost  
db: postgres  
user: postgres  
password: 12345  
port: 5432  

Пример создания таблиц:  
CREATE TABLE employees (  
    id SERIAL PRIMARY KEY,  
    name VARCHAR(100),  
    position VARCHAR(50),  
    salary FLOAT,  
    hours_worked INTEGER  
);

CREATE TABLE tasks (
    id SERIAL PRIMARY KEY,  
    title VARCHAR(100),  
    description TEXT,  
    status VARCHAR(20),  
    project_id INTEGER REFERENCES projects(id),  
    employee_id INTEGER REFERENCES employees(id)  
);

CREATE TABLE projects (  
    id SERIAL PRIMARY KEY,  
    name VARCHAR(100)  
);

3. Запустите приложение  
python main.py  
Откроется окно управления.

#### **Структура проекта и модули**
**main.py**  
Точка входа. Запускает графический интерфейс.

**gui.py**  
Основной графический интерфейс пользователя (Tkinter).  
Вкладки для сотрудников, проектов, задач, аналитика и загрузка/выгрузка CSV.

**models.py**  
Описания классов: Employee (сотрудник), Project (проект), Task (задача).  
Используется dataclass.

**storage.py**  
Работа с БД: подключение, добавление и чтение сотрудников/проектов/задач, обновление статусов, импорт CSV.

**analysis.py**  
Логика расчёта зарплат и аналитики выполнения проектов.

**utils.py**  
Вспомогательные функции: парсинг значений из интерфейса, безопасное преобразование чисел.

**test_models.py**  
Тестирование классов в **models.py**.  

#### **Импорт данных**  
Для загрузки сотрудников, проектов или задач используйте кнопки “Загрузить CSV” на соответствующих вкладках и укажите файл формата CSV.

#### **Зависимости**  
1. Python 3.10+  
2. pandas  
3. psycopg2  

#### **Прочее**  
Код легко расширяется новыми отчётами и вычислениями.  
Для управления базой рекомендуется использовать клиент, например, DBeaver.
